# Data Structures in C++

A menu-driven C++ project implementing fundamental data structures and their operations from scratch.

## Data Structures

* **Array** – Insertion, deletion, searching, sorting, updating
* **Linked List** – Insertion, deletion, searching, traversal
* **Stack using Array** – Push, pop, peek, display
* **Queue using Array** – Enqueue, dequeue, display
* **Binary Search Tree** – Insertion, searching, deletion, traversal

## Technologies

* C++
* Object-Oriented Programming
* Data Structures & Algorithms
* Pointers & Dynamic Memory Allocation
* Recursion

## Key Learning

Implemented core data structure operations from scratch and gained practical understanding of **pointers, recursion, memory management, and time complexity**.
